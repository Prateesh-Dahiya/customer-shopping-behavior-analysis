# Customer Shopping Behavior Analysis

## Project Overview

This project analyzes customer shopping behavior data using Python, PostgreSQL, and Power BI. The objective is to identify purchasing patterns, customer segments, and factors influencing customer buying decisions.

## Tools Used

- Python (Pandas, NumPy)
- PostgreSQL
- Power BI
- Vs code

## Dataset Information

- 3,900+ customer transactions
- 18 features
- Customer demographics, purchases, ratings, discounts, shipping preferences, and subscription status

## Project Workflow

1. Data Cleaning and Preprocessing
2. Feature Engineering
3. SQL Analysis
4. Dashboard Development
5. Business Insights and Recommendations

## Key Insights

- Clothing generated the highest revenue.
- Young Adults contributed the highest sales.
- Average Purchase Amount: $59.76
- Average Review Rating: 3.75
- Only 27% of customers had active subscriptions.
